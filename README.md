# loan_deal
Подготовка потока загрузки данных из нового источника от логической модели
Пользуясь логической моделью источников анализируем модель источников формируем маппинг слоя RDV указвая перечень нужных полей, ключи индексы
Пользуясь логической моделью слоя BDM формируем маппинги слоя BDM в которых указываем ключи, индексы, ограничения и типы данных
Формируем ресурсную модель потока, в которой указываем очередность блокировки таблиц.PostgreSQL хорошо масштабируется до 4–8 параллельных потоков записи на одну таблицу, если данные разбиты на независимые чанки. Большее количество потоков вызовет конкуренцию за блокировки.
Готовим постановку задачи на поток загрузки данных на слой IDL.
